# Daily Utils Hub

A fully client-side multi-tool web application with 10 utility tools built using vanilla HTML, CSS, and JavaScript.

## Features

✨ **10 Free Tools:**
1. 🔐 **Password Generator** - Generate secure passwords with customizable options
2. 📱 **QR Code Generator** - Create QR codes from text/URLs
3. 🎨 **Color Palette Generator** - Generate complementary color schemes
4. 😂 **Meme Text Generator** - Create memes with custom text
5. 👤 **Fake Data Generator** - Generate random test data
6. 📝 **Text Case Converter** - Convert text to different cases
7. 🔄 **Base64 Encoder/Decoder** - Encode/decode text and files
8. { } **JSON Formatter** - Validate and format JSON
9. ✅ **Todo List Manager** - Manage tasks with localStorage
10. 📋 **Note Taker Pad** - Markdown notes with live preview

## Key Features

- 🌓 **Dark/Light Mode** - Toggle between themes
- 📱 **Fully Responsive** - Works on desktop, tablet, and mobile
- 💾 **Offline Support** - No internet required, all client-side
- 🔒 **Privacy First** - No data leaves your browser
- 🎨 **Modern UI** - Clean Google-inspired design
- 🔍 **Search** - Quickly find tools

## How to Use

### Option 1: Open Directly
1. Navigate to the `daily-utils-hub` folder
2. Double-click `index.html` to open in your browser

### Option 2: Local Server (Recommended)
```bash
cd daily-utils-hub
python -m http.server 8000
```
Then open: http://localhost:8000

### Option 3: Live Server
If using VS Code with Live Server extension:
- Right-click `index.html`
- Select "Open with Live Server"
